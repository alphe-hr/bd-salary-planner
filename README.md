# BD Salary Planner 🇧🇩

A responsive, client-side Bangladesh lifestyle and salary budgeting calculator.

## Features

- Monthly income / salary input
- Job, business, freelance and mixed income types
- Dhaka / other city / rural cost factor
- Solo or family household planning
- Family members, children and students
- Education expenses
- Rent / own house / living with family
- Transport selection
- Loan / EMI
- Health and other fixed expenses
- Savings, emergency fund and investment recommendations
- Financial Health Score
- Dark mode
- Print / Save as PDF
- No backend required

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose your `main` branch and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Important

The calculator uses adjustable planning heuristics. It is not an official Bangladesh government budgeting formula or financial advice. Update the constants in `script.js` as your project evolves.
